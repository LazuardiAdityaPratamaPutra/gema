# Naskah video demo (≤ 5 menit)

Rekam di `/demo` pada layar 1280 px, lalu 20 detik di ponsel (atau jendela 390 px). Mode Demo memakai data fiktif; sebut itu di awal. Hapus `.data` dan mulai ulang server sebelum merekam, supaya keadaan awal sama dengan naskah.

Rubrik lomba yang dijawab: **fungsional**, **responsif**, **optimal**, **aksesibel**. Tiap bagian di bawah menyebut yang ditunjukkan.

## Cadangan bila waktu berlebih atau kurang

- Potong: bagian Bicara saja (butuh unduhan model sekitar 80 MB) dan Papan.
- Tambah: `/brankas/pengaturan` untuk Kode Paksa, pemulihan, dan passkey. Passkey bagus direkam di ponsel atau laptop dengan sensor sidik jari.

## Daftar periksa sebelum merekam

- `GEMA_DEMO` bukan `off`. `.data` bersih. Satu server saja (`pkill -f next-server` lalu `npm start`).
- Model suara sudah terunduh sekali bila ingin menunjukkan Bicara saja.
- Notifikasi dimatikan; zoom peramban 100%; tutup tab lain.
- Setelah merekam, jangan memakai data demo ini untuk kasus nyata.
